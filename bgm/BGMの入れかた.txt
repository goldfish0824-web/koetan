====================================================
  BGM の入れかた（こえたん／ことばリレー）
====================================================

■ 手順は 2 つだけ

  1. フリー素材の mp3 をダウンロードする
  2. このフォルダ（bgm）に入れて、名前を下のとおりに変える

       bgm/play1.mp3   ← 1曲め
       bgm/play2.mp3   ← 2曲め
       bgm/play3.mp3   ← 3曲め
       bgm/play4.mp3   ← 4曲め

     bgm/fanfare.mp3 は表彰のファンファーレです。消さないでください。

  ※ ファイル名は必ず半角の英数字で「play1.mp3」のとおりに。
     日本語の名前のままだと、サーバーによっては読めません。
  ※ 4曲そろえる必要はありません。1曲だけなら play1.mp3 だけでOK。
     入っていない番号は、ボタンを押しても自動で飛ばされます。


■ 使いかた（先生の画面）

  タイマーの下に、ボタンが2つ増えています。

    🎵 BGM：1曲め    … 押すたびに 1曲め → 2曲め →…→ なし → 1曲め と切り替わる
    🔊 音量：中      … 押すたびに 小 → 中 → 大 → 小 と切り替わる

  タイマーが止まっているときにボタンを押すと、5秒だけ試し聞きできます。
  授業が始まる前に、教室のスピーカーの音量をここで合わせてください。

  選んだ曲と音量は、その端末に覚えさせてあります。
  次の授業では、開いた時点で前回と同じ設定になっています。

  ・「スタート」を押すと同時に、BGM がすっと立ち上がります
  ・「一時停止」で BGM も止まり、もう一度「スタート」で続きから鳴ります
  ・時間切れになると、約2秒かけて自然に消えます
  ・「表彰する」を押すと BGM は消え、ファンファーレに切り替わります
  ・演奏中に BGM ボタンを押せば、その場で別の曲に差し替えられます


■ 重くなりませんか → なりません

  mp3 は index.html の中に埋め込んでいません。
  bgm フォルダから、必要になったときだけ読みに行きます。

  そして BGM を読みに行くのは「先生の画面」だけです。
  生徒のタブレットは bgm フォルダに一度もアクセスしません
  （生徒側が読み込むのは index.html ただ1つ、という状態のままです）。

  ですから、ここに曲を何曲入れても、
  ・生徒側の読み込みは 1 バイトも増えません
  ・40台のタブレットが一斉に接続しても、通信量は変わりません

  先生の端末が1曲ぶん（2〜4MB程度）を1回読むだけです。
  それも、先生が「コードを作る」を押した時点で先に読み込んでおくので、
  「スタート」を押した瞬間に間が空くことはありません。

  ※ 曲は 1曲あたり 5MB 以内をおすすめします。
    128kbps の mp3 なら、5分の曲でおよそ 4.5MB です。


■ どうして生徒の端末では鳴らさないのか

  生徒の端末はマイクを開いて音声認識をしています。
  同じ端末のスピーカーから音楽を流すと、マイクがその音楽を拾ってしまい、
  誤認識（言っていないのに正解になる、正しく言ったのに通らない）の原因になります。

  BGM は先生の端末から教室全体に流す。これがいちばん安全です。


■ 曲を選ぶときの注意

  ・ループ再生しています。途中でぶつっと切れて頭に戻るので、
    もともとループ用に作られた曲か、盛り上がりが一定の曲が向いています。
  ・ラウンドは最長7分です。曲がそれより長ければ、つなぎ目は聞こえません。
  ・生徒が声を出すゲームです。歌もの（人の声が入っている曲）は
    音声認識のじゃまになりにくい先生の端末側とはいえ、
    教室では聞き取りのじゃまになりがちです。インストがおすすめです。

  【利用規約の確認をおすすめします】
  このゲームを GitHub Pages などに置くと、mp3 も一緒にインターネット上に
  公開され、URL を知っていれば誰でもダウンロードできる状態になります。
  フリー素材でも「素材そのものの再配布」を禁止しているサイトがあります。
  配布元の規約で、次の2点を確認してください。

    ・Web 上に素材ファイルを置いてよいか（再配布にあたらないか）
    ・クレジット表記が必要か（必要なら README などに書いておく）

  ひっかかりそうな場合は、mp3 を GitHub には上げず、
  先生の端末のフォルダにだけ置いて、そこから index.html を開く
  ——という使い方なら、規約上の問題はまず起きません。


■ うまく鳴らないとき

  「🎵 BGMのファイルがありません」と出て押せない
    → ファイル名を確認してください。play1.mp3（半角・小文字）です。
      「play1.mp3.txt」のように拡張子が二重になっていないかも確認を。

  ボタンは出るのに音が出ない
    → 端末本体の音量とミュートを確認してください。
    → 一度「スタート」を押してみてください。ブラウザは、画面を1回も
      触っていない状態では音を鳴らさない決まりになっています。

  途中でぶつっと途切れる
    → 曲のループのつなぎ目です。別の曲か、より長い曲をお試しください。
